# Docs

These files are the context the agent reads before changing Peto. They are written like skills: each one says when it applies and what to do.

Read [game.md](game.md) for the quest itself. Then open only the skill that matches the task.

| Skill | Use it when |
|---|---|
| [skills/editing-a-quest/SKILL.md](skills/editing-a-quest/SKILL.md) | Opening this quest in Solarus Quest Editor, or turning a `.solarus` archive into an editable `data/` folder |
| [skills/import-resources/SKILL.md](skills/import-resources/SKILL.md) | Copying tilesets, sprites, sounds, or scripts from another quest or a resource pack |
| [skills/teletransportation/SKILL.md](skills/teletransportation/SKILL.md) | Doors, same-map warps, map changes, or scrolling edges between maps |

The tutorials these skills follow were announced in [New text tutorials on Solarus 2.0](https://www.solarus-games.org/news/2025-08-24-text-tutorials-progress/). The full articles live on the [Solarus documentation site](https://docs.solarus-games.org/).
