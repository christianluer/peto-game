# Peto

Original real-time action RPG, built as a Solarus quest.

## Run

Install the engine, then from this folder:

```bash
brew install solarus
make start
```

Maps and dialogue are edited in Solarus Quest Editor: https://www.solarus-games.org/download/

**C** swings the sword. **V** shoots the current spell (water for now). **F** talks to the companion who follows you. The cottage door leads into the yard.

## Layout

Game files live in `data/`. Agent context is in `AGENTS.md` and `docs/`. Asset licenses for the starter quest are in `CREDITS.md`.
